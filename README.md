# Projet UM5BM753 — Supervised and Unsupervised Learning for Biological Data

## Présentation
Projet réalisé dans le cadre de l'UE Supervised and Unsupervised Learning for Biological Data (M2 AIDA). Consignes détaillées : voir `02_Projects/00_docs/`.

## Sources
- `01_Data/raw/10_Breast_Cancer_Wisconsin_Diagnostic.csv` : jeu de données Breast Cancer Wisconsin (Diagnostic), non modifié depuis sa source d'origine.

## Structure du dossier
- `01_Data/` : fichiers de données
  - `raw/` : fichiers sources inchangés
  - `processed/` : fichiers nettoyés prêts à l'emploi
  - `data_dictionary.md` : description des colonnes
- `02_Scripts/` : scripts (Python), numérotés selon l'ordre d'exécution
- `03_Results/` : graphiques, tableaux exportés, modèles enregistrés
- `04_Report/` : notes de synthèse, présentations, rapport final

## Marche à suivre
1. Créer/activer l'environnement virtuel du projet.
2. Exécuter les scripts de `02_Scripts/` dans l'ordre numéroté.
3. Les productions sont écrites dans `03_Results/`.
