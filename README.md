# Breast Cancer Diagnosis — Orange3 component (WDBC/WPBC)

Orange3 counterpart to the Python component of UE 5BM753 (Ann-Solène Adelson, Anaïs Hluszko, Corentin Osta).

## Structure

- `data/raw/`: original, unmodified source files.
  - `10_Breast_Cancer_Wisconsin_Diagnostic.csv`: the Diagnostic (WDBC) dataset.
- `data/processed/`: files exported from the Orange3 workflow (e.g. `wpbc_processed.csv`).
- `workflow/`: the Orange3 workflow file (`Orange3_workflow.ows`).
- `report/`: the written report (`Written_report_Orange3.pdf`).
