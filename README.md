# Projet UM5BM753 — Supervised and Unsupervised Learning for Biological Data

## Présentation
Projet réalisé dans le cadre de l'UE Supervised and Unsupervised Learning for Biological Data (M2 AIDA). Consignes détaillées : voir `02_Projects/00_docs/`.

## Sources
- `01_Donnees/brutes/10_Breast_Cancer_Wisconsin_Diagnostic.csv` : jeu de données Breast Cancer Wisconsin (Diagnostic), non modifié depuis sa source d'origine.

## Structure du dossier
- `01_Donnees/` : fichiers de données
  - `brutes/` : fichiers sources inchangés
  - `traitees/` : fichiers nettoyés prêts à l'emploi
- `02_Codes/` : scripts (Python), numérotés selon l'ordre d'exécution
- `03_Resultats/` : graphiques, tableaux exportés, modèles enregistrés
- `04_Rapport/` : notes de synthèse, présentations, rapport final

## Marche à suivre
1. Créer/activer l'environnement virtuel du projet.
2. Exécuter les scripts de `02_Codes/` dans l'ordre numéroté.
3. Les productions sont écrites dans `03_Resultats/`.
